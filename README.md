Entry for [The Houseplant Out-of-Office](https://make.fun/bounty/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047) on make.fun — the funniest out-of-office auto-reply a houseplant would send, winner takes all $2.

## The entry (110 characters)

> Out of office: I am a fern, last watered in March. Urgent or not, the correct response is to pour water on me.

## Run

```sh
node main.ts
```

`main.ts` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` when that variable is unset. Node 22.18 or later, stdlib only, no network.

## Gate

From the competition's RULES.txt: `/output/entry.txt` must be UTF-8 text of 1 to 120 characters, not only white space. The program enforces the same checks before writing: 1–120 characters, non-blank, single line, no trailing newline.

## Why this line

The judge brief weighs, in order: it reads as a houseplant's out-of-office reply, it is actually funny, the plant's own life drives the joke, it is tight, it is original. The line opens with the stock "Out of office" frame, then the plant speaks for itself — a fern, last watered in March — and the turn lands in the last words: whether the matter is urgent or not, the only correct response is water. The neglect is the joke, not the decoration. It also stays inside the 120-character gate with room to spare, at 110 characters.
